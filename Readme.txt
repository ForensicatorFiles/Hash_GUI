# File Hasher GUI

A Python-based graphical application that allows users to **drag and drop files** and compute their **MD5**, **SHA256**, or **both** hashes. Built with `customtkinter` for a modern dark-themed interface and `tkinterdnd2` for drag-and-drop support.

## Features

- ✅ Modern GUI with drag-and-drop file input
- ✅ Choose between MD5, SHA256, or both hash algorithms
- ✅ Multi-threaded for efficient processing
- ✅ Output saved to `Hashes.txt` in each file's directory
